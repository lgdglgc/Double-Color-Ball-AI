## 🔮 AI 预测架构 (MoE v3.0)

### 1. 基础模型预测 (v2.0 修正版)
基础模型扮演“彩票数据分析师”，针对以下 5 种不同策略进行独立量化计分并预测：
*   **🔥 热号追随** — 计算多周期加权频率，追踪近期高频活跃号码。
*   **❄️ 冷号逆向** — 依据历史遗漏期数，捕获并计算回温信号，挖掘高遗漏冷号。
*   **⚖️ 平衡策略** — 精细化控制奇偶比（3:3/4:2）、大小比（2:4/3:3）、和值（100-120）及连号约束。
*   **📈 周期理论** — 进行超短期、短期、中期频率对比，筛选出趋势分大于 0 的上升期号码。
*   **🧠 综合决策** — 融合以上四个维度的标准化得分并进行加权计分推荐。

### 2. 混合专家超级裁判 (MoE v3.0)
超级裁判 AI（如 Claude Opus 或 GPT-120B）汇总最近 30 期历史数据和基础模型们的预测列表，进行共识与分歧评估：
*   **加权评分**：按 `热追(0.35) + 冷逆(0.25) + 平衡(0.25) + 周期(0.15)` 的算法权重给出号码综合得分。
*   **直接产出**：直接计算输出 5 组单式、1 组 8+2 复式大底和 1 组 4+4 胆拖池。所有组合在输出前由裁判进行全局硬约束校验。

## 🔄 自动化运行流程

1.  **定时触发**：每周二、四、日晚上 21:40（双色球开奖结束后约 25 分钟）。
2.  **获取数据**：Actions 执行 Python 爬虫脚本，抓取中国福彩网最新开奖结果。
3.  **预测生成**：将更新后的历史开奖数据注入 Prompt，依次调用各大 AI 模型与 MetaAI 超级裁判生成新一期预测。
4.  **自动归档**：对比上期预测结果与实际开奖结果，计算命中情况并写入历史记录。
5.  **推送部署**：自动将最新 JSON 数据 push 到 GitHub，触发 Vercel 自动秒级重新部署网站。

## 🚀 本地运行

1. 克隆本项目到本地。
2. 在终端（或 PowerShell）中进入项目文件夹，启动本地 HTTP 服务：
   ```bash
   python -m http.server 8000
   ```
3. 打开浏览器访问：`http://localhost:8000`

> ⚠️ **注意**：请勿直接双击打开 `index.html`，否则浏览器的同源安全策略（CORS）会拦截本地 JSON 数据文件的加载。

### 本地手动执行预测脚本

需要配置环境变量：

**Windows (PowerShell)**:
```powershell
$env:AI_API_KEY="您的_APIHubMix_或OpenAI_API_KEY"
# 可选：如果修改了代理端点
$env:AI_BASE_URL="https://aihubmix.com/v1" 

python generate_ai_prediction.py
```

**Linux / macOS**:
```bash
export AI_API_KEY="您的_API_KEY"
export AI_BASE_URL="https://aihubmix.com/v1"

python generate_ai_prediction.py
```
